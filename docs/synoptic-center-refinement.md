# Synoptic H/L Center Refinement (full-resolution accuracy fix)

**Date:** 2026-07-08 · **Current accuracy-audit follow-up:** 2026-07-11
**Authorization:** owner-blessed renderer accuracy change — the renderer byte-exactness rule was consciously waived for this fix (spec `docs/superpowers/specs/2026-07-07-maplibre-migration-design.md` §8a.6). Investigation: `.superpowers/sdd/center-accuracy-investigation.md`.

## The bias

H/L pressure centers were extracted entirely on the prepared (downsampled) grid: 25×15 (~250 km cells) in simple mode, 360×221 (~16 km) in detailed mode. Bilinear downsampling is a low-pass filter, so a core that does not sit on a grid node is averaged away — payload centers were **systematically less extreme** than the display-resolution field (36/40 sampled, mean ~1 hPa, worst 6.7 hPa: a Rockies high reported 1022 vs true 1028.7) and node-quantized in position (mean ~46 km, max ~148 km off). The old "refinement" (`refineCenterToRawGrid`) searched a fixed ±2-cell window of the same prepared grid, so it could never recover what downsampling had destroyed.

## The fix (`scripts/lib/synoptic-render.js`)

Candidates are now found once on the dedicated bounded center-analysis grid (target approximately 50 km over CONUS, capped at 128×80), independent of simple/detailed contour density. Each selected candidate is then **refined against the display-resolution MSLP field** (1600×980, ~3.7 km for the CONUS view):

1. **Light pre-smooth of the climb field (σ = max(6 km, native grid spacing/2), per `MODEL_NATIVE_SPACING_KM`).** NAM3km MSLP carries grid-scale (~3–9 km) terrain-reduction artifacts over steep terrain; the 6 km floor (~2 native grid lengths on the 3 km nests) suppresses single-pixel noise pockets while leaving synoptic cores (≥100 km scale) unattenuated. The half-native-spacing term keeps refinement from reporting positions sharper than the source physics — on coarser models the display field is a bilinear upsample whose ripples are interpolation, not weather: GFS (0.25° ≈ 27 km) presmooths at 13.5 km, NAM (12 km) at 6, and the 3 km nests keep the tuned 6 km behavior. The blurred field is **masked back to the raw field's NaN footprint** so the climb cannot follow blur-extrapolated values into no-data zones (the NAM native domain ends inside the CONUS view at the SE Atlantic corner, Mexico, and Canada edges). Computed once per pressure field (WeakMap keyed on the grid array; simple + detailed share it).
2. **Physical-radius monotone hill-climb.** Travel budget = one detection cell + 2·σ_detect (the detection-node quantization is ≤ ~0.71 cell and Gaussian smoothing displaces an asymmetric extremum by O(σ)), floored at 120 km. Containment: the climb only moves to strictly better values within a 5×5 neighborhood (step = 2), so regardless of budget it cannot cross a col/saddle wider than ~2 display pixels (~7 km at CONUS display resolution) into a neighboring system. Narrower cols are below the artifact scale that the pre-smooth σ (point 1) declares noise, so crossing them is intended noise-rejection, not a containment defect. The later accuracy audit removed global-extremum injection entirely; every retained center now passes finite locality/prominence gates.
3. **Seed rescue.** If a candidate's seed pixel has no data (detection grids extend into no-data zones through partial bilinear taps), the seed moves to the nearest real-data pixel before climbing, so edge markers report the field's actual edge extremum rather than an extrapolated value at an undefined position.
4. **Raw snap.** The emitted position and value are the raw-field extremum within ~2 pre-smoothing sigmas of the settled core — the marker agrees with hover inspection of the field. Values stay full-precision internally; **rounding happens once, at payload emit** (unchanged `Math.round`).
5. **Curation order.** Same-kind spacing (`selectDistinctCenters`) and opposing H/L overlap suppression run on detection-grid positions **before** refinement — marker curation is a detection-scale concern and sub-cell refinement must not flip it (observed: a 4.00-cell H/L gap drifting to 3.96 dropped a real Plains low). After refinement, same-kind centers within ~25 km collapse to the stronger candidate (two detection candidates can climb onto the same physical extremum).

Wiring: one canonical detection/refinement roster is generated and copied into simple and detailed vectors plus the manifest. Detail mode changes contour density, never the pressure-system analysis. Default marker schema is unchanged (`lat`/`lon`/`valueHpa`/`prominenceHpa`); positions are no longer node-quantized.

## Opt-in row-aware validation diagnostic (2026-07-11)

`--science-prototypes=rowAwareCenterValidation` enables a versioned, diagnostic-only comparison after the ordinary marker roster has been selected. For every retained detection-grid candidate, `row-aware-center-validation-diagnostic-v1` recomputes membership in the 200 km locality disc and 300–500 km prominence annulus using latitude-aware great-circle distance at each Mercator row. It also estimates the complete local-grid physical disc and applies the detector's 60% finite/in-domain quorum concept to row-aware samples. The emitted object records local-extremum agreement, contrast, coverage fraction/quorum, row-aware annular prominence, finite sample counts, edge truncation, and an aggregate pass flag.

The locality/prominence diagnostic is evaluated on the once-smoothed center-analysis MSLP field at the pre-refinement candidate because it is auditing the existing detection gate. After raw-field refinement and same-extremum deduplication, the emitted object separately reports great-circle nearest same-kind/opposing distances against the final emitted roster and whether they meet the nominal 450/300 km separation. It has **no effect** on marker rejection, ranking, H/L overlap resolution, position, pressure, refinement, or deduplication. This is intentional: a high-latitude synthetic case proves that the scalar-spacing and row-aware locality decisions can disagree, but a diverse real-regime validation set does not yet justify silently removing operationally useful edge or compound systems.

The same method metadata and canonical diagnostic-bearing roster are copied into simple and detailed vectors; the manifest records the prototype ID. Without the flag, neither the extra metadata nor per-marker object exists. On a warmed 119×73 synthetic field retaining 12 centers, the pinned 12-warm-up/80-pair run produced baseline median/p95 3.507/4.185 ms and diagnostic 6.487/7.764 ms, a +2.980 ms median marginal cost. The final gate rerun measured 3.264 ms baseline, 6.238 ms enabled, and +2.974 ms marginal. The harness emits all samples and the within-repetition paired-delta distribution so JIT/thermal variation remains visible. A representative diagnostic before coverage/roster fields was 429 JSON bytes; the capped addition remains on the order of tens of KiB per vector plus the manifest roster copy. Reproduce the harness with `node scripts/benchmark-science-prototypes.js`.

The shared prominence fallback was also corrected from divergent values (1.8 hPa in method metadata versus 2.4 hPa in detection) to one `DEFAULT_CENTER_PROMINENCE_MIN_HPA = 1.8`. The checked-in style already specifies 1.8, so default production rosters are unchanged; the correction affects only missing/incomplete style inputs and is pinned by a 2.0 hPa synthetic-center test.

## Companion fix: empty manifest `synopticCenters`

Manifests carried empty `synopticCenters` for 60/61 frames. Root cause: full builds split each hour > 0 into base + snow render parts; the snow part (`buildSnowRenderedArtifacts`) produces no synoptic fields, but the frame worker serializer **fabricated** `{highs:[],lows:[]}` for it and `applyRenderedFrameToManifestFrame` overwrote unconditionally — the snow part stomped the centers (and `pressureUploadMeta`) the base part had just written. Hour 0 never splits, which is why exactly one frame survived. Fixes: the worker passes absence through as `null` (`scripts/noaa-beta-frame-worker.js`), and the manifest merge only overwrites fields the render actually produced (`scripts/lib/local-artifact-manifest.js`).

## Historical Task 4.5 refinement verification (nam3km 20260707-1800Z, frames 000/012/024/036/048)

This byte comparison validated the 2026-07-08 refinement change in isolation. The later accuracy-audit center-scale, prominence, canonical-roster, and optional diagnostic changes intentionally supersede its whole-vector byte-identity result; the positional-error evidence remains the refinement validation.

Method: frames rebuilt into a temp cache root (live cache untouched); truth = same-system extremum of the display-resolution MSLP field (hover grid), found by hill-climb from the payload position (≤300 km, 5 px step — the investigation's method). ΔV > 0 = payload less extreme than truth. 50 centers matched 1:1 between old and new payloads; **no roster changes** across all 10 payloads.

Targets from §8a.6 (residual ≤0.5 hPa mean, ~8 km): met. The worst-case Rockies high (1022 vs true 1028.7) now reads 1029 at 0 km offset.
